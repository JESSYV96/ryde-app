# Car Rental

A mobile app for a small car-rental operator: create a rental (customer +
vehicle + dates), capture before/after vehicle photos with the camera, and
generate/share Quote and Summary PDFs.

See [CLAUDE.md](./CLAUDE.md) for the architecture (MVVM, feature-first,
tech stack, conventions).

## Get started

```bash
npm install
npx expo start
```

## Commands

- `npx expo start` — start the dev server
- `npx tsc --noEmit` — typecheck
- `npx expo lint` — lint
